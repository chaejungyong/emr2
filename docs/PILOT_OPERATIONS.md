# CardioSOAP Vet 파일럿 운영 기준

## 전환 전 필수 조건

- HTTPS를 적용하고 `DEPLOYMENT_MODE=pilot`, `SESSION_COOKIE_SECURE=1`, `LOGIN_LOCK_MINUTES=15` 이상으로 설정한다.
- MariaDB root 대신 이 데이터베이스에만 필요한 권한을 가진 전용 계정을 사용한다.
- `db_data/`, `storage/xrays/`, `storage/echo-videos/`, `.env`를 NAS snapshot과 별도 위치의 암호화 백업에 포함한다. Qdrant는 재색인 가능하므로 임상 원본으로 취급하지 않는다.
- 매일 자동 백업 성공을 확인하고 월 1회 격리 환경에서 MariaDB와 파일 저장소를 함께 복구한다. 복구 결과와 소요 시간을 기록한다.
- 실환자 전환 전에 테스트 환자로 예약→접수→검사→SOAP→설명→처방→청구→결제→종료를 통과시킨다.

## 장애 운영

- AI 또는 Qdrant 장애 시 AI 초안 생성을 중단하고 SOAP 편집기에 수동 기록한다. 임상·검사·처방·수납은 계속 사용한다.
- 웹 또는 DB 장애 시 종이 진료기록·처방·수납 양식을 사용하고 복구 후 담당자가 원기록을 전사하여 감사 메모를 남긴다.
- 영상 업로드 장애 시 원본을 병원 승인 저장소에 보관하고 복구 후 encounter에 연결한다.

## 병행운영 종료 기준

- 연속 10진료일 중 중대한 임상 누락 0건
- 일마감 대조 차이 0원
- 백업 복구 성공
- 권한·인증·CSRF·파일 접근 고위험 결함 0건
- 실제 X-ray와 Echo 영상 업로드·조회·SOAP 반영 확인

가격, 세금, 영수증 표시 항목과 개인정보 처리방침은 파일럿 시작 전에 세무·법률 검토를 받아 확정한다.

## 교재 지식베이스 갱신

- `clinical-book-v2` 색인은 교재명·판본·권·장 제목을 임베딩과 근거 메타데이터에 포함한다.
- 청킹 버전이 바뀐 경우 증분 색인을 사용하지 말고 관리자 화면에서 전체 재색인을 실행한다.
- 전체 재색인이 완료되어 `kb_active` alias가 전환되기 전에는 기존 컬렉션이 계속 사용된다.
- 재색인 후 개 MMVD, 고양이 심근병증, 폐고혈압, 급성 CHF 질문으로 Ettinger와 Critical Care 근거의 장·페이지가 읽을 수 있게 표시되는지 확인한다.
- 교재 원문은 환자에게 그대로 제공하지 않고, 수의사가 검토한 SOAP 초안과 짧은 근거 발췌만 사용한다.
